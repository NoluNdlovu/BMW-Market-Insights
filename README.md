# BMW-Market-Insights
Dashboard analyzing BMW Market Insights

## Overview
This project demonstrates a portfolio of BMW Market Insights

 
## What this project covers
Main Question: What drives used BMW prices & how do different factors compare?

 Factors include:
- Vehicle pricing
- Model
- Year
- Mileage
- Fuel type
- Engine specifications

 

## Who this is for
Consumers, Marketing Analysts, Sales Representatives
